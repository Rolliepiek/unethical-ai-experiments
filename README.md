A collection of ai experiments written in Rust, mainly about philosophical questions.
Our experiments are not made to be cutting edge technology, instead our goal is to make people think about ai.
Examples include things about emotions, ethics and consiousness.
All our experiments are written in Rust.
We name all of our experiments. For example with Charles I, Charles is the name for consiousness experiments and the I for version 1.
You can download the zip file to try the experiments by running the .exe files or building it using cargo.
